# Remmy

## Approve AI code changes from your wrist.

**No phone. No laptop. Just tap.**

---

## The Problem

You're using Claude Code. It's incredible.

But every time you step away — coffee, bathroom, meeting — your AI sits there **waiting for approval**. Blocked. Momentum killed.

**10 minutes wasted. Every. Single. Time.**

---

## The Solution

Your watch buzzes. You glance at your wrist. **Tap approve.** Claude continues coding. You never broke stride.

**Zero context switches. Zero wasted time.**

---

## How It Works

```
*buzz* *buzz*

┌─────────────────────────────┐
│  EDIT                  7:42 │
│                             │
│  src/auth.ts                │
│  "Add JWT validation"       │
│                             │
│  [ Approve ]    [ Reject ]  │
└─────────────────────────────┘

         👆 tap

     ✓ Claude continues
     You continue walking
```

---

## Get Started in 30 Seconds

```bash
npx remmy-cli
```

Enter the code shown on your Apple Watch. Done.

---

## Features

### 👆 One-Tap Approval
Approve or reject directly from the notification banner. The app doesn't even need to open.

### 🎤 Voice Commands
"Run the tests." "Fix the errors." "Commit with message auth hotfix."

### 📊 Live Progress
See exactly what Claude is doing — task lists, progress bars, completion status.

### ⌚ Complications
Watch face widgets show status at a glance. No app launch needed.

### 🔄 Mode Cycling
Normal, Auto, or Plan mode — just like Shift+Tab in Claude Code.

### 📳 Smart Haptics
Different vibration patterns for different events. You'll *feel* what needs attention.

| Step away from desk | Step away from desk |

| Come back 10 min later | Claude keeps working |

## Requirements

- Apple Watch Series 6 or newer
- watchOS 10.0+
- Mac running Claude Code

---

## Install Now

```bash
npm install -g remmy-cli
remmy-cli
```

Enter the pairing code from your watch. That's it.
